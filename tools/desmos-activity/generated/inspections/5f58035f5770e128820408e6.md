x1a = graph.number("x_{1a}")
x2 = graph.number("x_2")
x2a = graph.number("x_{2a}")

root1 = 
	when x1<0 "+${x1a}"
    otherwise "-${x1}"
root2 = 
	when x2<0 "+${x2a}"
    otherwise "-${x2}"
equation = 
	when x1<x2 "f(x)=(x${root1})(x${root2})"
    otherwise "f(x)=(x${root2})(x${root1})"

content:
when x1 = x1
"이전 화면에서 그린 포물선의 방정식은 다음과 같습니다:

`${equation}`

이 방정식과 포물선의 x 절편은 어떤 관계가 있을까요?
"

otherwise
"포물선의 X절편(근)이 존재하지 않습니다. 포물선의 X절편이 존재하지 않으면 액티비티를 원활히 진행할 수 없습니다.
