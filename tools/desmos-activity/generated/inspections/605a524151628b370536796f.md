## Script 3: Screen 2 cc (challenge)

```cl
notSubmitted = not(ccInput1.submitted)
functionUndefined = ccInput1.timeSinceSubmit > 0.01 and isUndefined(simpleFunction(ccInput1.latex))
functionInvisible = ccInput1.timeSinceSubmit > 0.01 and not(ccGraph1.number("P_0") = 1)
badSecondDerivative = ccInput1.timeSinceSubmit > 0.01 and not(ccGraph1.number("P_2") = 1) and not(ccGraph1.number("C_2") = 1)

preventSubmissionReason:

  when not(ccGraph2.number("v") = 1) "모든 함수에 레이블을 표시해 주세요."
  when isBlank(ccInput2.content) "답변을 설명해 주세요."
  when not(ccGraph2.number("t") > 2) "레이블을 확인해 주세요."
  when not(ccGraph2.number("c") = 1) "레이블을 제대로 표시했는지 확인해 주세요."
  otherwise ""

preventChallengeCreationReason:

  when notSubmitted "함수를 제출해야 합니다."
  when functionUndefined "올바른 함수를 입력해야 합니다."
  when functionInvisible "함수가 그래프에서 보여야 합니다."
  when badSecondDerivative "이 함수로는 적절한 f''(x) 함수를 만들 수 없습니다. 더 복잡한 함수를 입력해 보세요."
  otherwise ""

responseText: "시도 횟수: ${ccGraph2.number("C")}"

challengeBackground: graphLayer(ccGraph1.calculatorState)

challengeBounds: ccGraph1.bounds
```

## Script 5: Screen 2 06534422-3f57-44e3-97b0-7c224106f8d9 (exhibit/text)

```cl
feedback =

  when cc.script.functionInvisible "\n\n⚠️ 함수를 그래프에 표시할 수 없습니다. 다른 함수를 입력하세요." # the time since submit here is because there is an annoying flicker of the warning text while the graph calculates "V"
  when cc.script.badSecondDerivative "\n\n⚠️ 이 함수로는 적절한 `f''(x)` 함수를 만들 수 없습니다. 더 복잡한 함수를 입력해 보세요."
  otherwise "\n\n원하는 그래프를 만들 때까지 함수를 수정하고 다음 화면으로 진행하세요."
  
message = "이제 자신만의 `f\\left(x\\right)` 함수를 그릴 수 있습니다.

함수를 입력하면 `f\\left(x\\right)`, `f'\\left(x\\right)`, `f''\\left(x\\right)` 함수가 그래프에 표시됩니다."

content:

"${message}${feedback}"
```
